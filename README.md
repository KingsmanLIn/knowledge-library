# 知识书库 · Knowledge Library

集中保存知识类 HTML 书籍、交互教材和学习讲义，以及 economics work 项目中其他经用户确认的最终交付文件。

## 项目归档流程

economics work（亦称 economic work）项目中的所有对话均遵循：先完成并交付最终文件供用户审阅，说明拟上传文件与版本；用户明确确认本次文件或指定批次后再上传。此处保存的是仓库归档规则。若要在 ChatGPT 项目的所有对话中加载这条规则，还需将规则写入该项目的项目指令。

## 如何阅读

下载对应 HTML 文件后用浏览器打开；公式、字体和交互图解均已内嵌，可离线使用。GitHub 的文件页面用于查看源码与版本记录。

下载整个仓库后，也可以打开根目录的 `index.html` 浏览书目。

## 归档规则

- HTML 书籍统一保存到 `books/<学科>/`；其他最终文件按用途与学科保存到 `files/<学科>/` 等清晰目录。
- 同一本书或同一文件的修订优先更新原路径，用提交记录保留历史。
- 经用户确认上传新文件或修订后，同步更新 `catalog.json`、此目录和 `index.html` 中相关的目录信息。
- 保留每本教材自身的来源说明、适用条件和字体许可。
- 保持仓库私有；公开仓库或启用网页发布需要用户另行明确授权。

完整执行规则见 [AGENTS.md](AGENTS.md)。
