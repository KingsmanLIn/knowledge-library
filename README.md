集中保存知识类 HTML 书籍、交互教材和学习讲义。以后生成的这类内容默认归档到本仓库，并同步更新目录。

## 如何阅读

下载对应 HTML 文件后用浏览器打开；公式、字体和交互图解均已内嵌，可离线使用。GitHub 的文件页面用于查看源码与版本记录。

下载整个仓库后，也可以打开根目录的 `index.html` 浏览书目。

## 归档规则

- HTML 书籍统一保存到 `books/<学科>/`，文件名使用稳定的英文短名。
- 同一本书的修订更新原文件，用提交记录保留历史。
- 新书或内容修改后，同步更新 `catalog.json`、此目录和 `index.html`。
- 保留每本教材自身的来源说明、适用条件和字体许可。
- 默认保留仓库的私有可见性，不自动启用网页发布。
